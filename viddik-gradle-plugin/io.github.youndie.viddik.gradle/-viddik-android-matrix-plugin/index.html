ViddikAndroidMatrixPlugin

class ViddikAndroidMatrixPlugin : Plugin<Project>

The Android matrix: the module's fixtures captured on Gradle-managed emulators of several API levels, and an HTML page lining the levels up against each other.

plugins {
    id("io.github.youndie.viddik")
    id("io.github.youndie.viddik.android-matrix")
}
viddik { showroomTargets = true }

A plugin of its own, and a strictly additive one: io.github.youndie.viddik does not know it exists, viddikVerify/viddikRecord run exactly as they do without it, and it is the only class in this jar that names an AGP type — a module that never applies it never loads one.

It needs the registry in commonMain (showroomTargets), because that is the only registry an Android compilation can see, and a com.android.kotlin.multiplatform.library module, whose androidDeviceTest is where the capture runs.
